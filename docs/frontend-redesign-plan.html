个股终端前端优化方案

从「弹窗看盘」升级为「全屏工作区」——容器、图表内核、信息层级三层重构

2026-09-24 · 针对 tickflow-stock-panel v0.2.1 · 前端 React 18 + Vite + Tailwind

核心结论：问题不在配色和间距，在 容器选错了。弹窗天生做不出专业终端——屏宽只能用 57%，主图高度锁死 420px，控件只能往顶栏堆。先把容器换成全屏工作区，再谈其他。

真正的债务在图表内核：EChartsCandlestick.tsx 1718 行单体巨石，指标 / 缠论 / 手绘线 / 十字光标全耦合在一起。这是「每加一个功能都很痛」的根因，也是为什么它长得不像专业工具。

结论：分头抄，别整套照搬

容器形态抄 FreqUI / OpenBB——全屏工作台，不是弹窗。这是投入产出比最高的一步。

图表内核抄 KLineChart，而不是 Lightweight Charts。理由：LWC 虽然只有 45KB，但它不管指标、不管画线、不管副图——这三个恰好是你现在 1718 行胶水在干的事，换过去等于把胶水原样搬一遍。KLineChart 原生提供 60+ 指标、20+ 画线工具、主副图窗格，还有自定义 indicator / overlay API，缠论和定量结构可以直接注册进去。中文文档也是实打实的优势。

信息层级抄商业终端——顶栏只放「我是谁 + 现在多少钱 + 什么时间的价」，其余全部下沉。

三、目标架构

3.1 容器：从弹窗到独立路由

新增 /stock/:symbol 路由，渲染全屏 StockTerminal。原 StockPreviewDialog 降级为「快速预览」轻量版（保留给监控列表快速扫一眼用），两者共用同一套子组件。

// router.tsx —— 新增
{ path: 'stock/:symbol', element: <StockTerminal /> }

// StockTerminal.tsx —— 全屏工作区骨架
<div className="flex h-screen flex-col">
  <TerminalHeader symbol={symbol} />          // 标识 + 唯一价格 + 快照时间 + ⋯ 溢出菜单
  <ContextRibbon source={triggerInfo ?? abRow} />  // 触发上下文条 · 差异化记忆点
  <div className="flex flex-1 min-h-0">
    <WatchlistRail className="w-56" />          // 左栏 自选 · 可折叠
    <main className="flex-1 min-w-0">
      <ChartToolbar />                          // 周期 复权 画线 指标 · 下沉
      <KLinePro className="flex-1" />           // 主图 + 副图 · 高度自适应
    </main>
    <aside className="w-[180px]">
      <DepthPanel />                            // 盘口 · 三层级
      <NewsFeed />                              // 资讯 · 可折叠
    </aside>
  </div>
</div>

3.2 价格：单一数据源

把 quote 提升到工作区顶层一次拉取，顶栏、信息条、盘口全部消费同一份数据，并统一显示快照时间。这一条能直接消掉「35.04 vs 34.80」的信任危机。

// 顶层拉一次, 全工作区共享
const { data: quote } = useQuery({ queryKey: QK.quote(symbol), refetchInterval: 3000 })

// 顶栏 —— 唯一的权威价格
<span className="num text-2xl">{quote.price}</span>
<span className="num text-xs text-muted">快照 {fmtTime(quote.ts)}</span>

3.3 图表工具条：下沉

周期 / 复权 / 画线 / 指标已经在 StockDailyKChart 里了，把顶栏的区间预设和 DatePicker 也一并移下去，让工具条成为图表的「第一道边框」而不是悬浮层。

四、三阶段实施路线

P0 · 止血：换容器、统一价格、控件归位

2–3 天 · 不动图表内核 · 风险最低

  • 新增 /stock/:symbol 全屏路由，StockTerminal.tsx；StockPreviewDialog 保留为快速预览
  • 顶栏分层：主行只留 标识 + 价格 + 快照时间；区间预设、监控、最大化、刷新收进 ⋯ 溢出菜单
  • 价格单一源：quote 提升到顶层，顶栏 / InfoBar / DepthPanel 共用，统一带快照时间
  • 盘口 220 → 180px，信息分三层级（现价大字号 / 涨跌停色块 / 次要字段 11px 折叠）
  • 区间预设 + DatePicker 下沉到图表工具条

验收：全屏打开后主图高度 ≥ 视口 60%；整屏价格数字唯一；1920 屏下主图宽度 ≥ 1000px

P1 · 换内核：ECharts → KLineChart

1.5–2 周 · 收益最大 · 也是唯一的真风险

  • 引入 klinecharts，新建 KLinePro.tsx：主图 + 副图窗格 + 60+ 内置指标 + 内置画线
  • 缠论 / 定量结构注册为自定义 indicator + overlay（KLineChart 有官方扩展 API，不必再手写 SVG 覆盖层）
  • 双轨灰度：EChartsCandlestick 保留为 legacy，按 symbol hash 分流，异常可一键回退
  • 迁移完成后删除 EChartsCandlestick.tsx（1718 行 → 目标 ~400 行）
  • 确认不再需要 echarts 后从依赖移除，bundle 预计减少 180KB+

验收：日 K / 周月 / 5m~120m 全部走新内核；指标数量 ≥ 现有；缠论叠加与现状逐根对齐（对拍脚本已有可复用）

P2 · 终端形态：多窗格 + 键盘优先 + 响应式

2–3 周 · 依赖 P0/P1 完成

  • 三栏工作区可折叠，布局偏好写入 localStorage（左栏 / 右栏独立记忆）
  • 键盘优先：/ 聚焦搜索、1..9 切周期、Esc 关闭、← → 切上一只 / 下一只
  • 图表联动：左栏选股 → 主图 / 盘口 / 资讯同步切换，无需刷新
  • 响应式：≥1440 三栏 / 1024–1440 两栏（右栏折叠为抽屉）/ <1024 单栏（图表全宽，盘口抽屉）

验收：纯键盘可完成「搜索 → 看 K → 切周期 → 换股」全流程；1280 屏无横向滚动

五、设计系统：在现有 §6.0 上演进，不推翻

现有 CSS 变量体系（--base / --surface / --elevated / --border / --bull / --bear / --accent）结构是对的，保留。只做三处修补。

字体：换掉 Inter

正文 / UI 改用 IBM Plex Sans SC——中英同源、字重齐全、与数字搭配稳定，比 Inter 有辨识度，也不是烂大街的默认字体。价格 / 代码沿用已有的 JetBrains Mono。中英混排基线不齐的问题会一并解决。

排版：三档价格阶梯

顶栏主价格 24–28px / 600（一眼看到），盘口现价 18px，表格内价格 13px mono + tabular-nums。正文页 ≥16px，终端密集区可到 13px 下限。行高 1.6。

色彩：70-20-10 分配

中性（base/surface/border）占 70%，语义红绿只用于价格与 K 线占 20%，强调蓝只用于「当前激活状态」占 10%。现在红绿有溢出到 UI 状态的倾向，收回来。新增 --bull-dim / --bear-dim 供副图量柱使用。

动效：克制

切股用 120ms 淡入，不要 scale + blur（看盘时晃动干扰读数）。全部动效包在 @media (prefers-reduced-motion: no-preference) 内。

无障碍与响应式硬指标

  • 所有图标按钮补 focus-visible:ring-1 ring-accent——现有顶栏图标按钮无可见焦点态
  • 图标按钮命中区 ≥32px、间距 ≥8px（终端密集区的合理下限；非密集区仍按 44px）
  • 暗色下 --fg-muted (#8E8E96 on #18181B) 对比度约 5.6:1，正文合规；UI 边界 --border 需 ≥3:1，当前 #353539 偏暗，建议提到 #3F3F45
  • 表格在 <1024 转为卡片视图；侧栏转抽屉

六、记忆点：把「为什么来这里」做成主视觉

这是本项目唯一能吊打商业终端的地方

同花顺、通达信、TradingView 都只告诉你「这只股票现在多少钱」，不告诉你「你为什么打开它」。而 tickflow 是从自选、监控、异动扫描、选股结果跳进来的——triggerInfo 和 abRow 里已经躺着触发原因、触发时间、触发价位、信号标签，只是被渲染成一条 10px 小字塞在顶栏下面。

做法：把这条升级成图表上方独立的上下文条（context ribbon）——显示触发来源（监控规则名 / 异动窗口 / 选股策略）、触发时间、触发价位，并在主图上画一条对应价位线，右侧给一个「回到来源」链接。用户一眼就知道自己为什么在这，以及该看哪个价位。

这个功能数据现成、改动约 150 行、但辨识度极高——建议放在 P0 一起做，不要等到 P2。

八、明确不做的事

  • 不做 TradingView 那种 20+ 画线工具——先做 4 种（水平线 / 趋势线 / 矩形 / 价格标注），够用为止
  • 不做多股同屏对比图——性价比低，且分走主图空间
  • 不做移动端原生适配——看盘场景以桌面为主，移动端只保证「能看、不横向滚动」
  • P1 不一次性替换全部图表——先日 K，验证通过再动分时

最大的风险

P1 换内核时，缠论叠加层要整个重做——这是全项目最大的不确定项。建议：P1 开工前先用 KLineChart 的 overlay API 做一个缠论笔 / 中枢的最小验证（1 天），跑通再全面迁移。如果验证不通过，退回「ECharts 保留 + 只做 P0 和 P2」也是可接受的结果。
